# 基础

资产=现金+存货（上游原材料，库存）+应收账款+固定资产（厂房+办公设备）

固定资产是会贬值的

负债=预收账款（下游客户预收款）+应付账款（供应商借款）+ 借款

借款 = 股东权益 = 自己（本金+收益）+投资人（本金+收益）

资产负债表：现金+存货+应收账款+固定资产 = 预收账款+应付账款+借款



毛利 = 收入-直接成本（产品成本）

净利 = 毛利-间接费用（人力+水电+场地租金）

净利润 = 收入- 直接成本 - 间接费用

净资产收益率 = 净利润/净资产=净利润/销售收入+销售收入/总资产+总资产（自己+投资人的钱）/净资产（自己的）

- 能力

  销售净利润=净利润/销售收入，提高产品，产品好就卖得贵

- 速度

  资产周转率=销售收入/总资产，提升销售数量，从1个月卖1件（100元），改为1个月卖10件（10元+XX）

- 风险

  权益乘数=总资产/净资产，拉杠杆，赌博似的投资

# 辣椒

## 行话

花皮：辣椒果实表面出现杂色、斑点、褪色、斑块等异常现象的统称。这种辣椒因为“卖相”不好，商品价值会大打折扣

把子/帽子：指辣椒的果蒂（柄）。干辣椒交易中，"去把"和"带把"价格不同。

内子/种子：辣椒内部的籽。饱满程度直接影响干辣椒的香气和分量。

白壳：指辣椒内部隔开种子的胎座组织（白瓤）。在某些加工中，这个部分可能要去除。

统货：指不分等级、好坏、大小混在一起卖的货。价格相对较低。

捡把：指对辣椒进行人工分拣，去掉不好的、剪掉长把子的过程。

色价：这是一个专业术语，指辣椒红色素的含量。色价越高，辣椒颜色越红，越适合用来提取色素或作为调料上色。

皮子：有时候在流通中，也泛指辣椒的果皮部分，尤其当辣椒比较干、薄的时候。

## 过程

我是干辣椒的经销商，从新疆收购辣椒，装货卖给成都的批发市场老板或者销售。

1. 市场调研与采购准备
   1. 了解市场需求：分析成都市场的干辣椒需求量、价格波动趋势以及客户偏好（如辣度、颜色、形状等）。
   2. 确定采购品种：根据成都市场的口味和用途，选择适合的干辣椒品种（如红龙辣椒干、朝天椒干等）。
   3. 制定采购计划：包括采购数量、预算、时间安排等。
2. 联系新疆干辣椒供应商
   1. 寻找可靠的供应商：通过当地农业合作社、干辣椒加工企业或批发市场找到优质的干辣椒供应商。
   2. 实地考察：前往新疆干辣椒产地，实地考察干辣椒的质量、产量和价格。
   3. 签订采购合同：明确采购数量、质量标准、价格、交货时间等条款，确保双方权益。
3. 干辣椒收购 质量检验：
   1. 检查干辣椒的颜色（应为深红色或棕红色）、形状（完整无破损）、辣度（可通过品尝或检测设备判断）。
   2. 检查水分含量（一般控制在10%以下），避免受潮变质。 称重与计价：按照合同约定的价格和重量进行结算。
   3. 记录采购信息：详细记录每批干辣椒的采购时间、数量、价格、供应商信息等，便于后续管理。
4. 包装与装货
   1. 选择合适的包装方式：
      1. 使用密封袋或纸箱包装，防止干辣椒受潮。
      2. 包装上标注产品名称、规格、生产日期、保质期等信息。
   2. 装货准备：
      1. 确保运输车辆清洁、卫生，避免污染干辣椒。
      2. 根据干辣椒的数量和运输距离选择合适的运输方式（如普通货车、冷藏车等）。
5. 运输与物流
   1. 选择运输方式：
      1. 公路运输：新疆到成都的距离较远，公路运输是主要方式。可以选择普通货车运输，成本较低。
      2. 铁路运输：如果干辣椒数量较大，可以选择铁路运输，成本较低但时间较长。
   2. 物流跟踪：利用物流平台实时跟踪货物运输状态，确保货物安全到达。
   3. 保险：为干辣椒购买运输保险，以防途中出现意外损失。
6. 抵达成都后的处理
   1. 卸货与检验： 到达成都后，立即对干辣椒进行卸货，并再次检查质量，确保无损坏或变质。 如果发现质量问题，及时与供应商沟通解决。
   2. 仓储管理： 将干辣椒存放在通风、干燥的仓库中，避免阳光直射和高温。 对不同品种的干辣椒进行分类存放，便于后续销售。
7. 销售与分销
   1. 目标客户：
      1. 成都本地的批发市场、超市、餐饮企业、食品加工厂等。
      2. 通过线上平台（如电商平台、社交媒体）拓展销售渠道。
   2. 定价策略： 根据市场行情、采购成本和竞争对手的价格，制定合理的销售价格。 可以采用批发价和零售价两种模式，满足不同客户的需求。
   3. 促销活动： 推出优惠活动（如买赠、折扣）吸引客户。 与餐饮企业合作，提供定制化干辣椒产品。
8. 售后服务与反馈
   1. 客户反馈：定期收集客户的反馈意见，了解干辣椒的质量、口感和市场需求。
   2. 改进措施：根据客户反馈调整采购品种、包装方式或销售策略。
   3. 建立长期合作关系：与供应商和客户建立长期稳定的合作关系，提升品牌信誉。
9. 财务管理与总结
   1. 成本核算：计算采购成本、运输成本、仓储成本等，确保利润空间。
   2. 销售统计：记录每批干辣椒的销售情况，分析销售数据，优化采购和销售计划。
   3. 总结经验：总结每次交易的经验教训，为未来的业务发展提供参考。
10. 注意事项
