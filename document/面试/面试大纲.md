# 前端实习生面试提纲

## 考核标准（每项1-5分）

1. **专业基础与技术积累**：知识点准确，有项目经验支撑
2. **主动思考与逻辑分析**：能拆解问题、提出方案、考虑边界
3. **表达沟通与成长潜力**：表达清晰、有学习自驱力、对技术有热情

------

## 时间分配

| 模块                            | 时间   | 对应内容                         |
| :------------------------------ | :----- | :------------------------------- |
| 一、自我介绍与动机              | 3分钟  | 自我介绍、前端选择、实习期望     |
| 二、基础技术能力                | 8分钟  | HTML/CSS + JavaScript + 框架基础 |
| 三、实习经历深挖（选1-2个亮点） | 10分钟 | 中科智城 / 卓越智运 / 项目       |
| 四、工程化与综合素质            | 5分钟  | Git、学习能力、主动优化          |
| 五、开放与反问                  | 4分钟  | 开放性问题 + 反问                |

------

## 详细问题列表

### 一、自我介绍与动机（3分钟）

**考核：表达沟通、成长潜力**

1. 请用1-2分钟简单介绍自己，并说明你为什么选择前端方向。
2. 你对实习岗位的期望是什么？希望在这段实习中获得哪些成长？

------

### 二、基础技术能力（8分钟）

**考核：专业基础、逻辑分析**

#### HTML/CSS（2分钟）

1. 如何实现一个三栏布局（左右固定，中间自适应）？说出至少两种方法。
2. 你平时如何做移动端适配？rem、vw/vh、响应式布局你更倾向于哪种？为什么？

#### JavaScript（3分钟）

1. 值类型和引用类型

2. 简述闭包的作用和使用场景，有什么潜在问题？（可举例说明）

3. let const区别

4. 异步

5. 以下代码输出顺序是什么？请解释事件循环。

   ```
   console.log('1');
   setTimeout(() => console.log('2'), 0);
   Promise.resolve().then(() => console.log('3'));
   console.log('4');
   ```

#### TS

- 自定义类型
- 

#### 框架（Vue/React）（3分钟）

1. 你在项目中用到 Vue3 的 Composition API，请对比它与 Options API 的优劣。
2. 简述 Vue 的响应式原理（Vue2 的 defineProperty 与 Vue3 的 Proxy 区别）。

------

### 三、实习经历深挖（10分钟）

**考核：专业基础、主动思考、表达沟通**
（面试官任选1-2个方向，不必全部提问）

#### 🔹 中科智城（表单校验 / 国际化工具 / Vite优化）

1. 你提到“多字段联动与复杂校验场景”，能举一个具体的例子吗？你是如何设计校验规则和错误收敛机制的？
2. Vite 优化中“依赖拆分与按需加载”是如何实现的？打包体积减少 25% 前后有哪些数据或体验上的变化？
3. （可选）国际化工具有用到 AST，你能简单说下为什么选择 AST 而不是正则吗？

#### 🔹 卓越智运（微前端 / Vue2→Vue3 / 权限设计）

1. 参与基于 qiankun 的微前端架构，子应用接入时遇到过什么生命周期适配问题？如何解决样式隔离？
2. Vue2 迁移到 Vue3 过程中，状态管理从 Vuex 到 Pinia 做了哪些调整？如何保证迁移后业务稳定？
3. “基于 openid 的数据隔离方案”具体怎么设计？路由守卫如何结合后端权限？

#### 🔹 AI 智能哨兵（小程序 + 企业微信推送）

1. 企业微信消息推送中，Token 缓存与重试机制是如何实现的？如果 token 失效了，重试策略是什么？
2. 分页 + 条件筛选在云函数端是如何优化查询性能的？

#### 🔹 多模态 AI 生活助手（SSE + 虚拟滚动）

1. SSE 流式输出时，如果网络中断，前端如何处理？能否做到断线重连？
2. 虚拟列表在长对话场景中，如果消息高度不固定，你如何保证滚动位置正确？

------

### 四、工程化与综合素质（5分钟）

**考核：主动思考、学习能力、成长潜力**

1. **Git**：如果误提交了一个敏感文件到远程仓库，你会怎么处理？
2. **学习习惯**：你是如何跟进前端新技术和最佳实践的？最近有学习什么新技术吗？
3. **主动优化**：描述一次你在实习或项目中主动推动优化或解决问题的经历。

------

### 五、开放与反问（4分钟）

**考核：成长潜力、沟通表达**

1. **开放题**：假设你要从零搭建一个中型后台管理系统，你会如何选择技术栈并组织代码结构？
2. 平时怎么排查问题
3. 如何将ai引入开发工作流里面的
4. **反问**：你有什么想问我们的吗？（例如：团队技术栈、实习生培养方式、项目方向等）
